# 搜打撤 · 海岛战场

一个网页版 3D 多人"搜打撤"（搜刮 / 战斗 / 撤离）小游戏。跳伞进入海岛，搜刮装备、击败敌人、在风暴缩圈中生存，并在撤离点开启时登机撤离——活着离开才能带走全部战利品。

![玩法](https://img.shields.io/badge/%E6%90%9C%E6%89%93%E6%92%A4-%E6%B5%B7%E5%B2%9B%E6%88%98%E5%9C%BA-orange)

## 玩法概览

| 环节 | 说明 |
| --- | --- |
| 🪂 跳伞 | 每局开始乘坐运输机飞越海岛，按空格跳伞，W 俯冲加速，落地自动开伞 |
| 🔍 搜刮 | 8 处地标共 210+ 战利品点：地面物资秒捡；桌/柜/货架上的道具需**搜刮**（1.4~2 秒）；**保险柜**撬开需 6 秒，全岛 8 个，藏有 ≥¥1000 的高级物资 |
| ⚔️ 战斗 | 与真人玩家及 10 名 AI"拾荒者"交战，服务端权威判定伤害（爆头、护甲减伤、耐久损耗） |
| 🔎 检视 | 背包选中道具点"检视"或按 I：第一人称拿在手上旋转展示，附完整属性与价值详情卡；支持图片贴图道具 |
| 🌪 风暴 | 安全区分 6 个阶段收缩，圈外持续掉血；最终风暴清场 |
| ✈️ 撤离 | 4 个撤离点按 90 秒周期轮换开启，站在光圈内坚持 8 秒即撤离成功 |
| 💰 经济 | 撤离成功：背包全部物品折现入账并存入仓库；阵亡：全部物资掉落 |
| 🎒 背包 | 仓库物资可卖掉换赏金，或加入**携带清单**带进对局（开局自动扣出，阵亡即丢失） |
| 👕 捏脸 | 头/脸/上/下/鞋 **5 部位 × 10 预设** + **3 通道配色**（上衣/下身/肤色任意调色，取色器即时上身）+ 🎲 全部随机/重置；大厅 3D 预览站在**动态海岛场景**里（海浪/椰树/云/天穹）；AI 随机外观 |
| 📱 触屏 | 手机/平板浏览器自动出现虚拟摇杆 + 触屏按钮（开火/跳/蹲/跑/拾取/换弹/切枪/背包/地图） |
| 🌄 场景 | 渐变天穹 + 漂移云层 + 420 丛双向摆动草 + 三色树冠 + 波光水面；手账纸质风 UI |

## 快速开始

```bash
cd 搜打撤
npm install
npm start
```

浏览器打开 **http://localhost:3000**，注册账号即可进入。

> 需要 Node.js ≥ 16（推荐 18+）。若系统默认 Node 版本过旧，可用 `./start.sh` 自动选择新版本。

### 多人测试

局域网内其他设备访问 `http://<你的局域网IP>:3000`；或同一台机器开多个浏览器标签页 / 窗口，分别注册不同昵称，即可同场对战。

## 武器与物资

- **武器**：P92 手枪（初始）、蜂鸟冲锋枪、AK-7 步枪、LR-338 狙击枪、战术军刀
- **弹药**：9mm / 7.62 / .338
- **防具**：防弹衣 ×3 级（吸收 25%~55% 伤害，有耐久）、头盔 ×3 级（降低爆头倍率）
- **背包**：小背包 +4 格 / 战术背包 +8 格
- **医疗**：绷带、急救包、能量饮料（治疗 + 短时加速）
- **值钱货**：金条、古董怀表、显卡、神秘文物（撤离折现）

## 技术架构

```
搜打撤/
├─ server/            Node.js 后端（ESM）
│  ├─ index.js        Express 静态托管 + REST API + WebSocket
│  ├─ match.js        对局核心：缩圈 / 战斗判定 / AI / 撤离结算（10Hz 逻辑 + 12Hz 快照）
│  ├─ world.js        确定性海岛生成：47 建筑 / 246 墙体 / 159 战利品点 / 380 树
│  ├─ store.js        账号 / 仓库 JSON 持久化（data/players.json）
│  └─ bots.js 相关逻辑在 match.js 内
├─ shared/            前后端共用模块（同一份代码两端 import）
│  ├─ constants.js    物品 / 武器 / 缩圈 / 撤离点配置
│  └─ terrain.js      确定性海岛高度场（两端地形完全一致）
├─ public/            前端（Three.js r128，ESM 无构建）
│  ├─ js/game.js      3D 场景：地形网格 / 建筑 / 植被 / 特效 / 远程玩家插值
│  ├─ js/player.js    第一人称控制器：跳伞 / 物理 / 碰撞 / 射击
│  ├─ js/ui.js        HUD / 背包 / 小地图 / 大地图
│  ├─ js/main.js      状态机与消息路由
│  └─ js/net.js       WebSocket 客户端
└─ data/              运行时生成的存档
```

设计要点：

- **服务端权威**：伤害、命中、库存、缩圈、撤离进度全部服务端裁决；客户端位置上报有速度钳制（防瞬移）
- **单一世界事实**：地形 / 世界数据由服务端生成，前端通过 `/api/world` 拉取同一份；共享模块保证两端函数级一致
- **持久对局循环**：`对局(~8分钟) → 休整(25s) → 重置战利品与AI` 无限循环，中途可空降加入
- **零构建**：前端 ESM + importmap，three.js 本地托管，无打包步骤

## 常见问题

- **端口被占用**：`PORT=8080 npm start`
- **重置存档**：删除 `data/players.json` 后重启
- **想调难度 / 节奏**：改 `shared/constants.js`（缩圈阶段、武器数值、AI 参数、撤离点周期都是纯配置）
